# CatatUang_BackEnd

Catat Uang BackEnd merupakan API yang berfungsi untuk menjalankan proses aplikasi Catat Uang. Untuk saat ini API ini menyediakan route sebagai berikut :

1. Route *User* yang berfungsi sebagai proses login dan register akun
2. Route *Balances* yang berfungsi sebagai jumlah nominal saldo yang tersedia
